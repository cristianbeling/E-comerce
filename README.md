# SyntaxWear — Loja de Tênis e Sneakers

**Descrição**
- **Resumo:** Site estático de vitrine para venda de tênis e sneakers, com layout responsivo, hero, categorias, grade de produtos e rodapé com newsletter e links sociais.
- **Objetivo:** Template de front-end para e‑commerce ou protótipo visual.

**Funcionalidades implementadas**

Navegação responsiva: menu com ícone hamburguer para mobile.
Hero: destaque com título, subtítulo e CTAs.
Categorias: cartões clicáveis para estilos de produto.
Grade de produtos: cards para exibição de modelos.
Rodapé: formulário de newsletter, navegação e redes sociais.
Boas práticas: meta description e textos alternativos em imagens.
